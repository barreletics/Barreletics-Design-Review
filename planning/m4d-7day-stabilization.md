# M4D — 7-Day Stabilization Checklist

**Purpose:** Structured monitoring and verification for the first 7 days post-launch. Successful completion of this checklist satisfies the M4D exit criteria and authorizes transition to M4E.

---

## Day 1–3: Active Stabilization

### Daily Checks (Owner + Builder)

**Revenue & Orders:**
- [ ] Day 1: Revenue comparison to same day prior week — within expected range?
- [ ] Day 2: Revenue comparison — within expected range?
- [ ] Day 3: Revenue comparison — within expected range?
- [ ] Daily conversion rate comparison — no sustained decline?

**Technical:**
- [ ] Daily spot-check: open site, navigate 3 pages, check console for errors
- [ ] Monitor bounce rate by page — any page with >50% increase?
- [ ] Check Shopify speed report — no degradation?

**Customer Experience:**
- [ ] Monitor Help Scout for recurring theme-related issues
- [ ] Check for customer feedback via email, social, reviews
- [ ] Any cart abandonment increase? (Shopify admin → Analytics)

**SEO:**
- [ ] Day 1-3: Check Google Search Console for new crawl errors
- [ ] Verify no pages dropped from index unexpectedly
- [ ] Structured data validation (Google Rich Results Test on 2 URLs)

## Exit Criteria

ALL of the following must be true to declare stabilization complete:

- [ ] **7 consecutive days with no critical (P0) issues**
- [ ] **Revenue within expected range** (no sustained drop >15% vs. baseline, adjusted for seasonality)
- [ ] **No SEO ranking disruption detected** (top 10 keywords stable or improved)
- [ ] **All integrations stable** (analytics, tracking, support tools all functioning)
- [ ] **Zero unresolved P1 issues** (all high-severity issues fixed or documented with fix plan)
- [ ] **Owner declares stabilization complete**
