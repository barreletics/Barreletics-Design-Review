## QA

Harness: `planning/footer-sweep-qa/footer_shot.py`. Headless Chrome on macOS clamps windows to
500px, so the page loads in an iframe at the exact target width. Everything except the footer is
hidden in the iframe document — scrolling to the bottom is unreliable because lazy media keeps
growing the page while the shot is taken. Target files are never modified.

```
python3 planning/footer-sweep-qa/footer_shot.py --width 1440
python3 planning/footer-sweep-qa/footer_shot.py --width 390
```

`stale10=False` with checks reading: New drops and studio stories first · Early access to new
colorways and limited editions · Studio partner discounts and events · Care tips to extend the life
of your performance skins.
