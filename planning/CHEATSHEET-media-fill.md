# Media fill cheatsheet (open this when stuck)

**One line:** Media fills the column like One Pair — full-bleed, Cover, stretch to text row. Copy 50/50. Don’t invent.

**Lookup:** `planning/locks/MEDIA-FILL-50-50-LOCKED.md`

**Before touching liquid**
1. Is this a marketing split (50/50 family)? → use this card.
2. Axis name in one line (e.g. “Never slip media fills column”).
3. Push from Mac; liquid only; no index.json.

**60-second diagnose**
- Inset cream? → section padding
- Letterbox in frame? → object-fit / contain class
- Short column? → fixed height + align-items start
- Auth loop? → stop axis; Mac CLI
