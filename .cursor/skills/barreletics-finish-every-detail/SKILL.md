# Finish every detail

Andrew 2026-09-09: *DO not ever return a request without completing every detail.*

**A brief is work for you. Not a note to send someone else.**

## Sense it — STOP

You are about to fail if you:

- Write a handoff / email / .txt instead of editing the named page
- Finish item 1 and reply
- “Check and be ready” without making the change he asked for
- Skip verify because the JSON looks right

## Gate (copy into the turn)

```
EVERY DETAIL GATE
- [ ] Listed every numbered item and every “and” in the CURRENT message
- [ ] I am doing the work — not sending the brief onward
- [ ] Each item is done on the named page / section
- [ ] Verified on that page (desktop + mobile if named)
- [ ] Link only after all items are done
```

## Order

1. Write the checklist from his message.
2. Do them in order.
3. Verify each.
4. Then reply.

If one item is blocked, say which item and what is blocked. Do not call the rest done.
