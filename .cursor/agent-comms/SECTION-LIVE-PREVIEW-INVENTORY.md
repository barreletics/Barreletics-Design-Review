## Method
Rule from `cursor-to-grok.md` (2026-10-02): on this theme the TE only live-patches a `{% style %}` block that reads `{{ section.settings.ID }}` directly. Save-only: inline `style="--x: {{ assign }}"`, raw `<style>` with assigns, `{% render %}` snippets emitting vars (insets/type), `{% if %}`/class toggles. Static scan of all `sections/*.liquid` (schema settings incl. block settings; types range/color/number/select/checkbox/text_alignment = “visual”; settings never referenced in Liquid excluded). Also checked asset CSS `!important`, `layout/theme.liquid` `:root` vars, and `shopify:section:load` handlers in `assets/*.js`.

- **OK** = no visual settings, or every used visual setting read in `{% style %}`. **partial** = some. **broken** = none.
- `partial*` fifty-fifty: every range/colour/padding/height is live after PR #31; only layout selects/checkboxes remain Save-only (acceptable).
- “Used on” = `templates/*.json` + `sections/*-group.json` referencing the type.

## Cross-cutting findings
1. **`{% render %}` var snippets** — `section-inset-vars` (19 sections) and `type-override-vars` (22 sections) write into inline `style=`; never live. Can’t `{% render %}` inside `{% style %}` (broke before) → inline the 6 inset / 4 type lines per section.
2. **`!important` in `assets/barreletics-base.css`** — `.section-frame` margins (insets), `.section-frame--hide-*` display, `.mobile-stack--*` order (fifty-fifty, split-hero, collection-hero, about-split/joseph), and `.shopify-section:has(.sock-math)+… .pdp-reviews` background. Dual-write values must target the vars, not the properties. `chrome.css` `!important` on footer newsletter title + announcement items.
3. **Theme settings `:root`** — `layout/theme.liquid` sets `--section-padding-y`, `--heading-*`, `--split-media-h-mobile`, `--fullbleed-video-h-mobile` from global `settings.*` (Theme settings panel, not section). Fine to leave; sections fall back to these.
4. **JS re-init** — only `assets/chrome.js` listens for `shopify:section:load`, and only re-inits ambient videos (covers fullbleed/press/problem/collab/coperni/split-hero video). **Missing:** `initHeader()`/`initAnnouncement()` (header-group), `variant-selector.js` (buy-box, locked), Juicer embed re-init (home-juicer, locked). Section inline scripts (faq, reviews, variant-grid, proof-numbers, IO reveals) have no DOMContentLoaded guard so they re-execute on re-render — OK. No `{% stylesheet %}`/`{% javascript %}` tags found.
5. **Block settings** (visual-mosaic tiles, press-cards, reviews rating) need `#block-{{ block.id }}`-scoped rules inside the section’s `{% style %}` loop over `section.blocks`.
