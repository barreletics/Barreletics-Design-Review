## Budget allocation framework

| Bucket | Planning question | Guardrail |
|--------|-------------------|-----------|
| Paid media | What MER / contribution can we afford? | Scale on Shopify ROAS, not Meta claim |
| Inventory / manufacturing | What cover for heroes? | Avoid stockout on Open/Closed top colors |
| Content / SEO / Journal | Organic ~$2.21 rev/session — protect | Category Creation framing |
| Email | ~$2.25 rev/session — protect | List growth + flows |
| Partnerships | Wholesale/studio/ambassador ROI | Separate from DTC MER |
| Product / R&D | Owner-approved only | No assumed sock launches |

## Annual calendar (measurement)

| When | Activity |
|------|----------|
| Q4 prior year / Jan | Lock baseline targets; governance review ([24](./24-metric-governance.md)) |
| Each quarter | QBR ([21](./21-quarterly-business-review-framework.md)) |
| Mid-year | Re-forecast contribution & production |
| Year-end | Actuals vs plan; retire or rewrite TBD targets |

---

## Scenario planning (required)

Document three cases with the same KPI definitions:

1. **Base** — continue current efficiency  
2. **Invest** — higher paid + inventory for growth; temporary contribution dip allowed if Founder-approved  
3. **Conserve** — protect cash; cut weak ROAS; prioritize Organic/Email
