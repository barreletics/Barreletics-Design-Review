# 18 — Ambassador KPI Dashboard

**Purpose:** Measure ambassador program performance and brand amplification.  
**Audience:** Marketing, Founder, Partnerships.  
**Context:** Application → approval → onboard; commission/referral via codes or affiliate tooling (confirm terms before promising). Milestone 5 Growth Engine owns program ops (by name).  
**Related:** [04](./04-marketing-attribution-framework.md), [02](./02-north-star-metrics.md).

---

## Principles

1. Prefer **unique discount codes / UTMs** over guessing dark social.  
2. Comps and gifted product are **cost**, not revenue — track separately.  
3. Category Creation: ambassadors should teach Performance Skins vs socks, not sock wars.
