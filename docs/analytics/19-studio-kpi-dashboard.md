# 19 — Studio KPI Dashboard

**Purpose:** Measure studio partnership and studio-first category presence.  
**Audience:** Partnerships, Founder, Marketing.  
**Context:** Studio inquiry → qualification → onboarding; studio-first brand (barre, Reformer Pilates, Lagree, yoga).  
**Related:** [17](./17-wholesale-kpi-dashboard.md), [02](./02-north-star-metrics.md), GEO qualification in Growth Engine (by name).

---

## Principles

1. Studios are both **customers** (wholesale/retail) and **distribution of belief** (instructors).  
2. Studio density informs GEO page creation — data-gated.  
3. Separate vanity “studios emailed” from **active** relationships.
