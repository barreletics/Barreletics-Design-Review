    What are One-Off colors? +

    One-Offs are exclusive Performance Skin colorways outside the core lineup. Same grip system, same studio performance — limited color only. When a color sells out, it’s gone.

    When a color sells out, will it come back? +

    No. One-Offs are limited runs. Available now, then earlier drops stay sold out. If you want a color, grab it while it’s here.

    Are One-Offs the same shoe as core Closed Sole / Open Sole? +

    Yes. Same 360° grip, same stability, same Performance Skin construction. The difference is the exclusive colorway and limited availability — not a different product system.

    What size should I order? +

    Available now: M (Women 5–7.5, Men 6–8) and L (Women 8–10, Men 8.5–11). If you're between sizes, go larger.

    Closed Sole or Open Sole — which one? +

    Both perform identically — same grip, same stability. Closed Sole: heel and foot fully covered. Open Sole: heel exposed, mid-foot breathing hole. More grounded, barefoot feel. Natural toe splay. Choice is preference and feel only.

    What’s the return and warranty policy? +

    30-day returns on items in new, sellable condition. 90-day warranty covers manufacturing defects only. Free shipping on orders over $150.

    How do I clean them? +

    Warm soapy water, rinse, air dry. Never machine wash or bleach.
